# 六年之约 · Jack

一个给自己用的手机端记录应用：存钱、消费、健身、学习、阅读、每日三件事、习惯打卡、饮食饮水、体重与身体数据。

纯静态网页（PWA），无需账号、无需联网、无后端。所有数据只存在你自己的设备里。

---

## 最省事的方式：双击桌面图标（完全离线）

Windows 桌面上已经有一个 **「六年之约」** 快捷方式。

双击它，会用 Edge 的应用窗口直接打开应用：

- **不需要联网**
- **不需要启动本地服务**
- **不需要 Node**
- 窗口尺寸按手机比例，接近原生 App

它指向项目根目录里的单文件离线版 [六年之约.html](六年之约.html)（HTML、CSS、JS、图标全部内联，约 200 KB）。出差、飞机上、没有 Wi-Fi 都能正常记录。

> 数据保存在浏览器里，与 `http://localhost:5173` 版本属于不同来源，两边数据不互通。建议固定用桌面图标这一个入口，并定期在「我的 → 导出备份」保存 JSON。

换电脑或快捷方式丢失时，重新生成：

```bash
node tools/build-offline.js
powershell -File tools/make-shortcut.ps1
```

也可以把 `六年之约.html` 直接复制到手机：用微信文件传输助手 / QQ / AirDrop 发过去，在手机浏览器中打开即可离线使用（这是单文件网页，不是安装包）。想要手机桌面上的独立图标和完整离线能力，仍建议用下面「安装到手机桌面」的方式。

## 快速开始（局域网 / PWA 版）

### 电脑上预览

需要安装 [Node.js](https://nodejs.org/)（18 以上即可，无任何第三方依赖）。

```bash
cd jack6
node serve.js --open
```

或直接双击 **`start.cmd`**。

浏览器会打开 `http://localhost:5173`。

### 手机上使用

1. 电脑和手机连接同一个 Wi-Fi。
2. 启动服务后，终端会打印类似：

   ```
   电脑访问: http://localhost:5173
   手机访问: http://192.168.1.23:5173
   ```

3. 在手机浏览器里打开「手机访问」那个地址。

### 安装到手机桌面

- **Android（Chrome / Edge）**：右上角菜单 →「安装应用」或「添加到主屏幕」。
- **iPhone（Safari）**：底部分享按钮 →「添加到主屏幕」。

> 说明：Service Worker 离线缓存要求 HTTPS（或 localhost）。通过局域网 `http://192.168.x.x` 打开时，应用本身可以正常使用，也能添加到桌面，但可能无法离线打开。想要完整的离线体验，把整个文件夹上传到任意支持 HTTPS 的静态托管即可，例如 GitHub Pages、Netlify、Vercel、Cloudflare Pages。

## 健身模块的细节

这是整个应用里做得最重的一块。

### 记录一次训练

- **类型**：力量、有氧、HIIT、球类、身心、户外、其他。
- **项目**：内置 30 种常见运动（跑步、骑行、游泳、跳绳、篮球、羽毛球、瑜伽、徒步……），每种都有对应的 MET 值。
- **基础数据**：日期、时长、体重、距离（跑步/骑行/游泳/徒步等）、平均心率、主观强度 RPE（1–10）。
- **训练部位**：胸、背、腿、肩、手臂、核心、臀、全身，可多选。
- **力量训练**：可逐条添加动作，记录组数、次数、重量，自动计算：
  - 训练容量 = 组数 × 次数 × 重量
  - 预估单次最大重量（1RM，Epley 公式）= 重量 × (1 + 次数 ÷ 30)
- **有氧训练**：距离、时长，自动估算消耗。
- **热量**：默认按 `MET × 体重(kg) × 时长(小时)` 估算，也可以手动改成本人设备上的实际数值。
- **备注**：睡眠、状态、疼痛、教练反馈等都可以写。

### 自动统计

- 本周训练次数、总时长、总消耗、总容量
- 连续训练周数、最近训练日历热力图
- 每个动作的历史最佳（按预估 1RM）
- 各训练部位的次数分布
- 最近训练明细，可展开查看动作和备注

> 热量为估算值，用于趋势对比，不构成医疗或营养建议。MET 参考《体力活动纲要》（Compendium of Physical Activities）的常见取值。

## 接入小米手表数据

网页 / PWA 无法直接读取小米手表的实时健康数据：小米没有开放面向网页的健康接口，部分小米账号也没有 Health Connect 同步。因此这里采用**官方导出文件 + 本地导入**的方式，安全、可离线、不需要任何第三方授权。

### 导出

1. 手机打开「小米运动健康」→ 我的 → 隐私中心。
2. 进入「管理您的数据」→ Mi Fitness / 运动健康 → 申请导出。
3. 小米会发送下载链接到邮箱，网页上会显示压缩包密码。
4. 解压后得到 CSV 文件。

### 导入

应用内「我的 → 手表数据 → ＋ 导入 CSV」，选择文件：

- **`*_MiFitness_hlth_center_sport_record.csv`**：运动记录。会写入「健身」，包含运动类型、日期、时长、距离、设备热量、平均/最高心率、步数，并在卡片上标注「手表」。
- **`aggregated_fitness_data.csv`**：每日汇总。步数、睡眠、活动消耗、静息心率会写入「手表数据」首页和每日列表。
- 也接受包含上述字段的 JSON。

文件只在浏览器里用 `FileReader` 解析，不会上传。重复导入按设备记录 ID / 日期自动去重。设备提供的热量优先使用，缺失时按 MET × 体重 × 时长估算。

> 小米不同机型、地区、App 版本的导出字段可能略有差异。如果某个文件导入后识别为 0 条，请把前几行（可去掉个人数据）发给我，我按实际字段调整解析。
>
> 想做到「打开即自动同步」需要原生 Android App 或 Health Connect，网页版做不到；导入方式适合每隔一段时间补齐记录。

## 导入微信支付账单

微信没有给个人开放账单 API，网页 / PWA 也无法监听微信支付通知，所以**不能自动同步每一笔消费**。可行且安全的做法和手表一样：导出微信官方账单，在本地导入。

### 导出

1. 微信 → 我 → 服务 → 钱包 → 账单。
2. 右上角「常见问题 / ⋯」→ 账单下载。
3. 选择「用于个人对账」，选好时间范围，填写邮箱。
4. 邮箱会收到加密压缩包，密码通过微信支付消息发送。
5. 解压得到 CSV 文件。

### 导入

应用内「消费 → 导入微信账单」，或「我的 → 数据管理 → 导入微信账单」，选择 CSV。

- 只导入「支出」，自动按交易对方和商品归类到餐饮、交通、购物、学习、娱乐、居住、医疗、其他。
- 转账、红包、提现、零钱充值、理财、信用卡还款、退款不会计入消费。
- 按微信交易单号去重，反复导入同一个月不会重复记账。
- 导入的记录在消费明细里带「微信」标签。
- 文件只在浏览器本地解析，不上传。

> 部分退款暂不做自动冲抵；大额退款可手动记一笔或在导入后自行调整。不同微信版本的 CSV 列名可能略有差异，识别为 0 笔时把表头发来即可适配。

## 数据与隐私

- 数据保存在浏览器的 **localStorage**，键名 `jack6.v1`。
- 不上传服务器、不需要登录、没有统计脚本。
- 清除浏览器数据 / 卸载浏览器 / 更换域名，都会导致数据丢失。
- 建议定期在「我的 → 导出备份」保存一份 JSON。换设备时用「导入备份」恢复。
- 同一台设备的不同浏览器（Safari / Chrome）数据互不相通；添加到主屏幕后请固定使用同一个入口。

## 自定义

大多数设置可以直接在应用内「我的」里改：目标金额、起止日期、期初存款、月预算、身高体重、饮水目标、每周训练次数。

想改代码里的默认值或文案：

- 默认设置：`assets/app.js` 顶部的 `DEFAULT_SETTINGS`
- 消费分类：`EXPENSE_CATS`
- 运动项目与 MET：`ACTIVITIES`
- 力量动作库：`EXERCISE_LIB`
- 主题色与字体：`assets/style.css` 顶部的 CSS 变量

修改后如果手机上是通过 HTTPS 安装的，请重新打开一次应用让 Service Worker 更新缓存（导航请求已改为网络优先）。

## 开发自检

```bash
node tools/make-icons.js        # 重新生成 PNG / ICO 图标
node tools/build-offline.js     # 重新打包 六年之约.html
powershell -File tools/make-shortcut.ps1   # 重建桌面快捷方式
node tools/shot.js              # 截图到 .shots/
node tools/test.js              # 55 项表单/数据冒烟测试
node tools/test-offline.js      # 单文件离线版自检
```

`shot.js` / `test.js` / `test-offline.js` 依赖本机已启动的 Edge/Chrome 调试实例，仅用于开发，不影响应用运行。

修改 `assets/app.js` 或 `assets/style.css` 后，记得重新运行 `node tools/build-offline.js`，桌面离线版才会更新。

## 关于「六年之约」

「六年之约」的灵感来自抖音创作者 **@Jack要加油** 发起的个人成长计划：从 2024 年 12 月 30 日到 2030 年底，用六年时间存下 100 万、坚持健身、学习和阅读，每天记录开心的事、不开心的事和当天的思考，每天比昨天好一点点。

本项目是一个非官方的个人记录工具，与原作者无关联。目标金额、起止日期等都做成了可修改的设置，你也可以用它记录属于自己的「六年」。
